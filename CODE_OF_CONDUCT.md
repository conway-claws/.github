# Code of Conduct

Conway CLAWS runs these projects for the benefit of the Conway High School community: students, families, teachers, and neighbors. Participation here is held to the same standard as participation in any CLAWS space.

## Expectations

- Be respectful. Disagree with the work, not the person.
- Keep it factual. These repositories deal in public records and public event data; claims belong with sources.
- Protect people. Never post personal information about students, families, or staff in an issue, a pull request, or a commit. If something here exposes personal information, report it privately (see below) rather than drawing attention to it in public.
- No harassment, hate speech, or personal attacks, in any project space.

## Enforcement

Concerns go to president@conwaypto.org and are reviewed by the CLAWS Executive Board. Reports involving personal information go to privacy@conwaypto.org. Maintainers may edit or remove content and restrict participation to uphold this standard.
