# Security Policy

These projects are built to have a small attack surface: public data in, public files out, no user accounts, and no credentials in the repositories. district-library runs with zero secrets by design; calendar-sync's only secret is a repository Actions secret that never appears in code or output.

## Reporting

- A vulnerability in the code, the Actions workflows, or the published sites: email president@conwaypto.org. Do not open a public issue for anything exploitable before it is fixed.
- Exposed personal information about a student, family member, or staff member: email privacy@conwaypto.org. This is treated as the most urgent report type.

Reports get a reply from the CLAWS board. There is no bug bounty; this is a volunteer-run 501(c)(3).
