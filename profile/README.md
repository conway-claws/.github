# Conway CLAWS

Community Leaders At Work for Students: the 501(c)(3) parent-teacher organization for Conway High School in Conway, Arkansas.

This organization holds the public infrastructure CLAWS runs for the CHS community. All of it operates in the open: public code, public data, automated daily builds, and nothing that requires a credential to verify.

## What lives here

**[calendar-sync](https://github.com/conway-claws/calendar-sync)** builds the CLAWS community calendar. Multiple public sources (the district event feed, the CHS live feed, a curated roundup of CHS-adjacent groups, and the CHS morning announcements) merge into one subscribable calendar at [calendar.conwaypto.org](https://calendar.conwaypto.org), with a sub-feed per category. A GitHub Action rebuilds it every day. MIT licensed.

**[district-library](https://github.com/conway-claws/district-library)** catalogs the public records of the Conway Public Schools district: one structured record per document, a plain-text extraction wherever the source allows one, and a machine-readable catalog built for search tools and AI assistants. Originals stay with the district; every record carries its source and retrieval date. MIT licensed.
